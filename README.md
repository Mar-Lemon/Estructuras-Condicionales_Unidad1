# Descripción de los Programas
# 1. Clasificación de triángulos
Solicita las tres longitudes de un triángulo y determina si es equilátero (tres lados iguales), isósceles (dos lados iguales) o escaleno (todos los lados diferentes), comprobando primero que las medidas correspondan a un triángulo válido.
# 2. Año bisiesto
Pide al usuario un año y determina si es bisiesto aplicando la regla lógica: divisible entre 4 y no entre 100, o divisible entre 400.
# 3. Conversor de calificaciones
Toma una calificación numérica en la escala de 0 a 100 y le asigna la equivalencia en letra correspondiente (A, B, C, D o F) mediante condicionales `elif`.
# 4. Comparación de tres números
Solicita tres números al usuario y determina mediante comparaciones condicionales cuál de ellos es el mayor y cuál es el menor.
# 5. Tarifa de entrada
Determina el costo de la entrada a un parque basándose en la edad ingresada: menores de 12 años ($50), de 12 a 17 años ($80) y adultos de 18 años en adelante ($120).
